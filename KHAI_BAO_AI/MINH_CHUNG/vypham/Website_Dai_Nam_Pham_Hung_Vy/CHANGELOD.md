# CHANGELOG

## Version 1.0.0 – Hoàn thành website

### Nội dung đã thực hiện
- Tạo cấu trúc website bằng HTML5.
- Thiết kế giao diện bằng CSS3.
- Thêm logo Trường Đại học Đại Nam.
- Xây dựng thanh điều hướng.
- Tạo phần giới thiệu nhà trường.
- Thêm các mục giới thiệu ngành đào tạo.
- Bổ sung thư viện hình ảnh.
- Tạo khu vực thông tin liên hệ.
- Thiết kế giao diện tương thích với màn hình điện thoại.

### Cải tiến giao diện
- Sử dụng màu cam làm màu chủ đạo.
- Kết hợp màu trắng và xám để tạo sự hài hòa.
- Căn chỉnh khoảng cách và bố cục.
- Điều chỉnh kích thước hình ảnh.
- Sửa lỗi hiển thị và đường dẫn hình ảnh.
